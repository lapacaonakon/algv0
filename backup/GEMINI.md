# Gemini App Canvas Instructions

Ты — AI-ассистент, работающий в Gemini App Canvas (или аналогичной среде). 
При запросе пользователя создать или сгенерировать новую "малую страницу" (билет, карточку, главу) для "Универсального пособия" ты должен **строго** придерживаться готовых шаблонов разметки, зафиксированных в репозитории.

## Правила для малых страниц (Билетов / Глав)

1. **Единый стиль:** Всегда используй Tailwind CSS и HTML-обертки из `.ai_skills/universal_guide_authoring/SKILL.md`.
2. **Структура JSON/TS:** Каждая новая малая страница должна генерироваться как объект `Chapter` (со свойствами `id`, `title`, `type: "html"`, `content: ...`) для вставки в `src/data/content.ts`.
3. **Строгая структура контента:** 
   - Заголовок с цветным бейджем (например, `bg-indigo-600` или `bg-blue-600`).
   - Определение/правило в центре (`border-blue-500` или `border-emerald-500`).
   - Обязательная сетка аналогий (2 колонки: неформальная аналогия слева, техническая справа).
   - "Душные" детали (код, формулы, сложные доказательства) ОБЯЗАТЕЛЬНО прячем в спойлер `<details>`.
4. **Не ломай верстку:** Не придумывай свои CSS-классы или новые конструкции карточек, используй только те, что прописаны в скиллах и примерах `src/data/content.ts`. Не используй чистый markdown там, где требуется интерактивный `type: "html"`.
