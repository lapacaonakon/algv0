# Структура приложения и парсинг элементов

Если вы хотите парсить HTML конспект внешними инструментами, элементы разбиты на следующие логические сущности, к которым привязаны предсказуемые теги и классы.

## Заголовки
* Заголовки секций: Используют стандартный тег `<h2>` и вложены внутрь секции `<section id="question-X">`.
* Подзаголовки: Используют тег `<h3>`.

## Текст и параграфы
* Обычный текст содержится в тегах `<p>`.
* Блоки "Шиза" (Аналогии) и другая текстовая инфографика имеют класс `.analogy-block` и `.info-block`. Внутри них текст также разбит на параграфы `<p>`.

## Математические формулы
В приложении используется MathJax. 
* В самом исходном коде страницы (и внутри тегов) формулы записаны в **чистом LaTeX виде** с границами-маркерами `$` (inline) и `$$` (block).
* Таким образом, при извлечении текстового содержимого (например, через `innerText` в браузере или парсинге текстовых нод), формулы автоматически остаются в валидном Markdown-формате латеха (например: `$\Delta = b^2 - 4ac$`).

## Картинки и визуализации (Схемы)
Вместо обычных `<img>` в приложении используются векторные элементы-схемы:
* Они помещены внутрь оберток с классом `<div class="img-placeholder">`.
* Все отрисовки находятся внутри векторного тега `<svg>`.
* Подпись к картинке, если она есть, идет сразу после SVG и имеет класс `<div class="img-caption">`.

## Списки
* Стандартные списки оформлены через `<ul class="list-none ...">` или `<ol>`, элементы списка внутри имеют тег `<li>`.

## Валидный экспорт в Markdown (встроенный)
Экспорт перехватывает основные структурные компоненты HTML, используя встроенный подход:
1. Заголовки `<h2>` и `<h3>` заменяются на `##` и `###`.
2. Элементы `.analogy-badge` получают выделение маркерами жирности `**`.
3. Теги `<svg>` заменяются строкой-заглушкой `[ Иллюстрация: ... ]` с подстановкой подписи из класса `.img-caption` (если она присутствовала).
4. Элементы списка `<li>` получают маркер `-`.
5. Результат извлекается в виде текста и чистится от лишних переносов строк. В результате получается корректный Markdown файл.
