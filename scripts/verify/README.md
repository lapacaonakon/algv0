# Проверки приложения (`npm run verify`)

Три уровня проверок, которые можно гонять локально и в CI. Headless-браузер не
нужен: DOM даёт `jsdom`, Python — `pyodide` из `node_modules` (тот же CPython
3.12, что грузится в браузере пользователя, только без CDN).

```bash
npm run verify          # всё сразу: unit → эталонные коды → DOM
npm run verify:unit     # 38 проверок разбора живых данных
npm run verify:code     # 46 эталонных кодов страниц под настоящим трейсером
npm run verify:dom      # 139 сценариев: страницы, панель, матрицы, кнопки
npm run verify:probe    # диагностика панели Python во времени (не тест)
```

Отчёты кладутся в `tmp/verify/` (каталог в .gitignore): `report.json` —
помарочно по DOM-сценариям, `reference-code.json` — по эталонным кодам.

## Что именно проверяется

### `verify:unit` — `live-matrix.test.mjs`
Разбор данных, которые присылает компилятор, в матрицу произвольной
размерности: список списков, рваные строки, словарь словарей, ключи-пары
`"(0, 3)"` (так снапшотятся tuple-ключи Python), `"inf"`/`"-inf"`,
числа-строки, обрезка до 64×64. Отдельно — что матрицей НЕ является плоский
список и словарь по именам (`dist`, `prev`): иначе визуализация приняла бы
чужие данные за сетку. Плюс `pickLiveVar` (приоритет имён) и `clampIndex`
(индексы пользователя вне диапазона демо).

### `verify:code` — `check-reference-code.mjs`
Каждый референсный код из `PAGE_SYNC` выполняется настоящим CPython под тем же
`sys.settrace`-трейсером, что и панель компилятора. Проверяется: нет ошибки,
трасса не оборвана по лимиту шагов, шагов больше нуля (иначе панель показала бы
пустой листинг), и **каждая переменная, обещанная странице, реально создаётся
кодом** — иначе визуализация физически не может за ним следовать. Сюда же
ловятся предупреждения интерпретатора, которые иначе попали бы в панель
«Результат».

### `verify:dom` — `browser-checks.tsx`
Настоящее приложение монтируется в jsdom (`App` целиком: навбар, содержание,
глава, визуализация, панель Python), сценарии кликают кнопки и печатают в
редакторе.

| Группа | Что делает |
| --- | --- |
| A. страницы (22 × 3) | каждая глава монтируется; бейдж источника данных на месте; панель открывается, редактор и кнопка-«глаз» на месте; автозапуск инициализации настоящим Python не роняет панель и переключает визуализацию на данные кода; в разметке нет `NaN`/`undefined`/`[object Object]`; нет кнопок без имени |
| B. Флойд: размерности (10) | 5×5, 10×10 (больше демо — старый краш), 3×3 с `inf`, неквадратная 4×6, словарь словарей, ключи-пары, плоский список, 80×80 (обрезка), пустая матрица, чужое имя `D` и `k/i/j` вне диапазона |
| C. матричные страницы (6) | префиксные суммы 2D и разреженная таблица на данных другой размерности, запросы вне границ |
| D. графы путей (2) | Дейкстра/Форд-Беллман с вершинами `0…4` вместо `A…G`: таблица значений пользователя появляется, кнопки ручного проигрывания гаснут и оживают обратно |
| E. эталонный код (46) | прогон кода в CPython → финальный снимок подаётся в визуализацию → она обязана перейти на данные компилятора и не показать мусор |
| F. редактор (6) | код из одних комментариев, синтаксическая ошибка, полная очистка — редактор не исчезает, связь снимается; «глаз» вставляет эталон и возвращает инициализацию; код не перетекает между страницами; Esc возвращает редактор из листинга |
| G. lite-режим (1) | `?lite=1` отдаёт текст без навигации, демонстраций и компилятора |
| H. доступность (2) | в панели подписаны все кнопки в обоих режимах, управление шагами на месте; бейдж честно различает три состояния источника |

Фильтры: `HAR_CHAPTERS=floyd,dijkstra`, `HAR_SKIP=A,E`, `HAR_SYNC=floyd`.

## Как это заведено в приложение

* `window.__algv0PythonRuntime` — точка подмены интерпретатора в
  `PythonCompiler.tsx`. В браузере пользователя поле не определено, и панель
  грузит Pyodide с CDN как раньше; харнес кладёт туда локальный runtime.
* Состояние визуализаций передаётся через `emitVizState`/`useVizRuntime`
  (`src/data/vizStepBus.ts`) — те же события, что шлёт панель, поэтому проверка
  идёт по боевому пути, а не через внутренние API компонентов.
